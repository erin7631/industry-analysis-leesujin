4. 분석 방법 및 출처

한국은행 2023년 산업연관표(생산자가격 기준)의 과제 원본 엑셀 4종에서 각 분류별 산업 코드와 생산·수입·부가가치유발행렬을 추출하였다. 국산투입계수 Ad, 수입투입계수 Am, 부가가치계수 v를 이용하여 L=(I−Ad)⁻¹, M=AmL, V=diag(v)L의 관계를 검증하였다.

생산·수입·부가가치유발계수는 해당 행렬의 열 합계이며, 영향력계수는 L의 열 합계를 전체 열 합계 평균으로 나눈 값, 감응도계수는 L의 행 합계를 전체 행 합계 평균으로 나눈 값이다. 모든 계수는 무차원이며, 각 분류의 평균과 순위는 해당 분류 내부에서 산출한다.

분류별 원표에서 미리 계산한 값을 브라우저에서 비교·정렬한다. 수입유발계수가 낮거나 생산유발계수가 높다는 사실만으로 산업의 수익성이나 정책적 우위를 단정할 수 없다. 분류 수준 간 계수는 집계 범위 차이로 직접 일대일 대응하지 않는다.
